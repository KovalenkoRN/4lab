# Лабораторная работа 4 «Калькулятор скидок» (React + Vite)

Приложение считает цену товара со скидкой в зависимости от категории и с учётом НДС 22 %.
Основной компонент — `src/DiscountCalculator.jsx`.

## Запуск

```
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).
